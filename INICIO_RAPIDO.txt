┌─ PASSO 1: PREPARAÇÃO ─────────────────────────────────────────────────┐
│                                                                         │
│  1. Crie uma conta Twilio GRÁTIS:                                     │
│     → https://www.twilio.com/try-twilio                              │
│                                                                         │
│  2. Após login, vá para: https://console.twilio.com                  │
│                                                                         │
│  3. Copie seus valores:                                              │
│     • Account SID                                                     │
│     • Auth Token                                                      │
│     • WhatsApp Number (ex: whatsapp:+15551234567)                   │
│                                                                         │
│  4. Abra o arquivo .env e adicione seus valores                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 2: INSTALAÇÃO ─────────────────────────────────────────────────┐
│                                                                         │
│  Terminal (Windows, Mac ou Linux):                                    │
│                                                                         │
│  $ cd seu_bot_whatsapp                                               │
│                                                                         │
│  $ python -m venv venv                                               │
│                                                                         │
│  $ venv\Scripts\activate    # Windows                                │
│  $ source venv/bin/activate # Mac/Linux                             │
│                                                                         │
│  $ pip install -r requirements.txt                                   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 3: TESTAR LOCALMENTE (SEM WHATSAPP) ───────────────────────────┐
│                                                                         │
│  Terminal:                                                             │
│  $ python whatsapp_bot.py                                            │
│                                                                         │
│  Navegador:                                                            │
│  → http://localhost:5000/test                                         │
│                                                                         │
│  Digite mensagens de teste:                                           │
│  • "oi" → Bot responde com boas-vindas                              │
│  • "horário" → Mostra horário de funcionamento                      │
│  • "preço" → Mostra tabela de preços                                │
│  • "menu" → Mostra todas as opções                                  │
│                                                                         │
│  Cada resposta é testada em tempo real!                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 4: CONECTAR SEU WHATSAPP (Sandbox) ────────────────────────────┐
│                                                                         │
│  1. Acesse: https://console.twilio.com/sms/whatsapp/sandbox          │
│                                                                         │
│  2. Você verá um código tipo: "join apple-juice"                     │
│                                                                         │
│  3. Abra WhatsApp no seu celular                                      │
│                                                                         │
│  4. Envie uma mensagem EXATAMENTE assim para: +1 415-523-8886       │
│     "join apple-juice"                                               │
│                                                                         │
│  5. Você receberá uma mensagem de confirmação                         │
│                                                                         │
│  6. Agora seu número está conectado ao sandbox!                      │
│                                                                         │
│  💡 DICA: Agora qualquer mensagem que você enviar para o número      │
│     Twilio será respondida automaticamente pelo seu bot!             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 5: CONFIGURAR WEBHOOK (Conectar Bot ao Twilio) ────────────────┐
│                                                                         │
│  A. Se está testando localmente (ngrok):                              │
│                                                                         │
│     1. Baixe ngrok: https://ngrok.com/download                       │
│     2. Terminal: ngrok http 5000                                      │
│     3. Copie a URL tipo: https://abc123def.ngrok.io                 │
│                                                                         │
│  B. Configurar no Twilio:                                             │
│                                                                         │
│     1. https://console.twilio.com/sms/whatsapp/sandbox               │
│     2. Procure: "When a message comes in"                           │
│     3. Digite: https://abc123def.ngrok.io/webhook                   │
│     4. Método: HTTP POST                                             │
│     5. Salve                                                          │
│                                                                         │
│  C. Teste:                                                             │
│                                                                         │
│     Envie uma mensagem WhatsApp → Bot deve responder!                │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 6: PERSONALIZAR RESPOSTAS ───────────────────────────────────┐
│                                                                         │
│  Abra: whatsapp_bot.py                                               │
│                                                                         │
│  Encontre a função: processar_mensagem(texto_entrada)                │
│                                                                         │
│  Adicione novos comandos:                                             │
│                                                                         │
│  elif 'seu_comando' in texto_entrada:                               │
│      return "Sua resposta aqui! 😊"                                 │
│                                                                         │
│  Salve e reinicie o bot (Ctrl+C e python whatsapp_bot.py novamente) │
│                                                                         │
│  Teste no /test → Deve funcionar!                                    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─ PASSO 7: DEPLOY NA NUVEM (Heroku) ──────────────────────────────────┐
│                                                                         │
│  1. Criar conta: https://heroku.com                                   │
│                                                                         │
│  2. Instalar Heroku CLI: https://devcenter.heroku.com/articles/      │
│     heroku-cli                                                        │
│                                                                         │
│  3. Terminal:                                                          │
│     $ heroku login                                                     │
│     $ heroku create seu-bot-whatsapp                                 │
│     $ git push heroku main                                            │
│                                                                         │
│  4. Adicionar credenciais:                                            │
│     $ heroku config:set TWILIO_ACCOUNT_SID=seu_valor               │
│     $ heroku config:set TWILIO_AUTH_TOKEN=seu_valor                │
│     $ heroku config:set TWILIO_WHATSAPP_NUMBER=seu_numero          │
│     $ heroku config:set VERIFY_TOKEN=seu_token                     │
│                                                                         │
│  5. No Twilio, mudar webhook para:                                    │
│     https://seu-bot-whatsapp.herokuapp.com/webhook                  │
│                                                                         │
│  6. Pronto! Seu bot está funcionando 24/7 na nuvem! 🎉               │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
