📞 DÚVIDAS? LEIA ISTO PRIMEIRO
═════════════════════════════════════════════════════════════════════════

"ModuleNotFoundError: No module named 'flask'"
→ Ative o venv: source venv/bin/activate (ou venv\Scripts\activate)
→ Reinstale: pip install -r requirements.txt

"Invalid API credentials"
→ Abra .env e COPIE EXATAMENTE seus valores do Twilio Console
→ Não deixe espaços em branco
→ Reinicie o bot

"Webhook not receiving messages"
→ Veja GUIA_COMPLETO.md seção Troubleshooting
→ Use ngrok para testar localhost
→ Confirme a URL no Twilio Console

"Port 5000 already in use"
→ Mude no código: app.run(port=5001)
→ Ou feche a aplicação anterior

Mais dúvidas?
→ Leia GUIA_COMPLETO.md (tem 100+ perguntas respondidas!)
→ Veja twilio.com/docs/whatsapp
→ Consulte os exemplos em EXEMPLOS_AVANCADOS.py

🎯 RESUMO TÉCNICO
═════════════════════════════════════════════════════════════════════════

Stack:
  • Python 3.8+
  • Flask (web server)
  • Twilio API (WhatsApp gateway)
  • python-dotenv (credentials)
  • SQLite (opcional, para histórico)

Arquitetura:
  Usuário → WhatsApp → Twilio API → Seu Servidor Flask → 
  Processador → Resposta customizada → Twilio → WhatsApp do Usuário

Fluxo de Mensagem:
  1. Usuário envia mensagem WhatsApp
  2. Twilio recebe e faz POST para seu /webhook
  3. Flask processa a mensagem
  4. processar_mensagem() retorna resposta
  5. MessagingResponse() envia de volta
  6. Twilio entrega ao usuário

Deploy:
  • Local: python whatsapp_bot.py
  • Teste: http://localhost:5000/test
  • Nuvem: Heroku, Render ou Railway
  • 24/7: Configure webhook com URL pública
