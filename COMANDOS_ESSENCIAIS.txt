1️⃣ SETUP INICIAL (Execute uma única vez)
═════════════════════════════════════════════════════════════════════════

# No terminal, dentro da pasta do projeto:

# Criar ambiente virtual
python -m venv venv

# Ativar (Windows)
venv\Scripts\activate

# Ativar (Mac/Linux)
source venv/bin/activate

# Instalar dependências
pip install -r requirements.txt

✅ Você deve ver "(venv)" no início da linha do terminal

═════════════════════════════════════════════════════════════════════════
2️⃣ INICIAR O BOT (Escolha uma opção)
═════════════════════════════════════════════════════════════════════════

# OPÇÃO A: Interface Interativa (RECOMENDADO)
python run_bot.py
# Menu amigável com todas as opções

# OPÇÃO B: Iniciar Bot Diretamente
python whatsapp_bot.py
# Bot inicia direto

# OPÇÃO C: Rodar Testes
python test_bot.py
# Executa 10+ testes automatizados

═════════════════════════════════════════════════════════════════════════
6️⃣ DEPLOY HEROKU (Passo a passo)
═════════════════════════════════════════════════════════════════════════

# Instale Heroku CLI: https://devcenter.heroku.com/articles/heroku-cli

# No terminal:
heroku login

heroku create seu-bot-whatsapp

git add .

git commit -m "Initial commit"

git push heroku main

# Adicionar variáveis de ambiente:
heroku config:set TWILIO_ACCOUNT_SID=seu_valor

heroku config:set TWILIO_AUTH_TOKEN=seu_valor

heroku config:set TWILIO_WHATSAPP_NUMBER=whatsapp:+seu_numero

heroku config:set VERIFY_TOKEN=seu_token_secreto

# Ver logs:
heroku logs --tail

# No Twilio, atualizar webhook para:
# https://seu-bot-whatsapp.herokuapp.com/webhook
